이 파일이 아티클 작성 템플릿이다. 프로젝트 루트의 `articles/` 폴더에 `.mdx` 파일을
추가하면 목록과 상세 페이지가 자동으로 생긴다. 파일 이름이 그대로 주소가 된다 —
이 글은 `/articles/hello-world`다.

## 프론트매터

파일 맨 위 `---` 사이에 `title`·`date`·`description` 세 가지를 적는다.
`title`을 비우면 파일 이름이 제목이 되고, `date`는 목록 정렬 기준이다.

## 쓸 수 있는 문법

**굵게**, *기울임*, `인라인 코드`, [링크](https://nextjs.org), 그리고 표까지 된다.

| 항목 | 값 |
| --- | --- |
| 포맷 | MDX |
| 위치 | `articles/` |

> 인용문도 이렇게 쓴다.

```ts
const greeting = "hello world";
```

- 목록도 된다
- MDX라 나중에 리액트 컴포넌트도 넣을 수 있다

이 파일은 예시일 뿐이니 지우거나 첫 글로 덮어써도 된다.
